# Junior Astronaut Mission Trainer 🚀

**An interactive space exploration and astronaut training experience designed to inspire the next generation of explorers.**

## Overview

Junior Astronaut Mission Trainer is an interactive educational web application developed for the **2026 NASA Space Apps Challenge**.

The project aims to make space exploration more accessible and engaging for younger audiences by transforming astronaut missions into interactive learning experiences.

Rather than simply reading about space exploration, users get to experience the challenges astronauts face through mission-based activities, problem-solving exercises, and interactive mini-games.

## 🎯 Objectives

- Make space exploration and astronaut missions more accessible to younger learners.
- Introduce users to the challenges, responsibilities, and problem-solving involved in space missions.
- Encourage curiosity about space science, engineering, and technology.
- Combine interactive gameplay with educational content to create an engaging learning experience.

## 🛰️ Key Features

- **Interactive Missions:** Explore astronaut mission scenarios and complete different objectives.
- **Mission Challenges:** Solve practical problems inspired by the tasks and responsibilities involved in space exploration.
- **Mini-Games:** Participate in short interactive challenges that test observation, decision-making, and problem-solving.
- **Educational Experience:** Discover the science and engineering concepts behind space missions through hands-on interaction.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal.
